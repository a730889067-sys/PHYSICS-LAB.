# حَرَكة | Haraka Animator

تطبيق Android عربي لصناعة وتحريك شخصيات العصا إطارًا بإطار.

## الحالة الحالية

هذه هي النواة الأولى القابلة للبناء: محرر مفاصل على Canvas، إطارات متعددة، نسخ/حذف الإطار، تشغيل الحركة، الجلد الشفاف للإطار السابق، تراجع/إعادة، حفظ المشروع محليًا، وتصدير الإطار الحالي كصورة PNG.

## البناء

يُبنى التطبيق تلقائيًا عبر GitHub Actions عند دفع التغييرات، ويمكن تشغيل البناء يدويًا من تبويب Actions.

## ملاحظة

هذه نسخة تأسيسية وليست بعدُ بديلًا كاملًا لكل ميزات Stick Nodes Pro. ميزات مثل تصدير MP4/GIF، استيراد ملفات التطبيقات الأخرى، المكتبة السحابية، والمقاطع الجاهزة تحتاج مراحل تطوير واختبار لاحقة.
