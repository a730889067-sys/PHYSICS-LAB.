# حَرَكة | Haraka Animator

تطبيق أندرويد عربي مستقل لصناعة وتحريك شخصيات العصا بإطارٍ إطار، بواجهة داكنة مهيأة للهاتف.

## المزايا الموجودة في الحزمة الحالية

- محرر متجهي مع مساحة عمل قابلة للتحريك والتكبير.
- إنشاء شخصيات متعددة وتحريك المفاصل بالسحب.
- خط زمني لإضافة الإطارات ونسخها وحذفها.
- معاينة الحركة وتحديد معدل الإطارات.
- Onion Skin لعرض وضعية الإطار السابق.
- توليد إطارات وسيطة بالتنعيم الخطي.
- أدوات خط ودائرة ومستطيل ونص.
- استيراد الصور والخلفيات والصوت إلى الإطار.
- لون وسُمك وتأثيرات للأجزاء والعناصر.
- كاميرا قابلة للتحريك والتكبير والتصغير والتدوير، وربط عنصر باليد.
- حفظ المشروع بصيغة `.haraka` وفتحه وحفظ تلقائي محلي.
- تصدير PNG وGIF، وتصدير الفيديو عبر الترميز المدعوم من WebView (MP4 أو WebM بحسب الجهاز).
- حفظ الملفات في مجلد Downloads/Haraka من داخل التطبيق.

## مصدر التطبيق

المصدر الكامل موجود في `Haraka_Animator_Source.tar.xz`. لفكّه، افتح الأرشيف ثم ادخل إلى مجلد `HarakaAnimator`. هذا هو المشروع الذي يبنيه سير العمل.

## إنشاء APK

كل تحديث على الفرع `main` يشغّل GitHub Actions. عند نجاح البناء، افتح تبويب Actions، واختر آخر عملية ناجحة، ثم نزّل عنصر `Haraka-Animator-APK` وستجد داخله `Haraka-Animator.apk`.

## حدود النسخة الحالية

هذه نسخة تأسيسية موسعة وليست مطابقة 100% لكل وظائف Stick Nodes Pro. استيراد ملفات Stick Nodes/Pivot، المكتبة السحابية، أدوات التحديد والتحرير المتقدمة، ومزج الصوت النهائي مع الفيديو ما زالت خارج الحزمة الحالية. يدعم التطبيق التحرير المحلي دون الحاجة إلى حساب أو API مدفوع. يجب اختبار التصدير على جهاز أندرويد الفعلي لأن دعم MP4 يعتمد على WebView وبرامج الترميز المتوفرة.

## المتطلبات

- Android SDK 35 للبناء.
- JDK 17 وGradle 8.9.
- الحد الأدنى لأندرويد داخل الحزمة: API 29.
